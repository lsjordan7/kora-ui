# Kora UI — Mockup

Interactive mockup for **Kora**, an AI-powered mobile wellness app with Apple Watch companion.

Built with React + Vite + Tailwind CSS v4.

## Design System

| Token | Value | Usage |
|---|---|---|
| Base | `#0F0A1E` | Deep space purple background |
| Surface | `#1A1030` | Card / panel backgrounds |
| AI Accent | `#00E5C8` | Bioluminescent aqua — AI elements |
| Human Accent | `#E8A598` | Rose gold — warmth, readiness |
| Text | `#F2F0FF` | Primary foreground |
| Muted | `#9B97B8` | Secondary labels |

**Typography:** Fraunces (display) · DM Sans (UI) · Space Mono (AI voice)
